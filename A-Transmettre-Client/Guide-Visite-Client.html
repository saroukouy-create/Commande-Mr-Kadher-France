Le point à connaître avant le rendez-vous

Ce qui change par rapport au site

Trois fichiers indépendants

Sur le site, les modules se transmettaient les résultats tout seuls via une base commune. Ici, chaque classeur garde ses propres résultats : reportez le profil et le score obtenus dans l'Outil de profilage, ainsi que le résumé de l'Intégrateur de balance, directement dans les champs prévus en haut de la Trame de rapport — une recopie de quelques chiffres, rien de plus.

Le parcours conseillé

Dans cet ordre, pendant le rendez-vous client

Profilage

Ouvrir Outil-de-Profilage.xlsx et remplir le questionnaire avec le client. Le score et le profil apparaissent en direct sur l'onglet Résultats — pas de bouton à cliquer pour valider.

Balance

Ouvrir Integrateur-de-Balance.xlsm. Sur PC : bouton Choisir un fichier... pour un import automatique. Sinon : coller directement les comptes dans l'onglet Données (colonnes Compte/Libellé/Année N-1/Année N) — la classification par cycle se fait ensuite toute seule, sur l'onglet Analyse.

Rapport

Ouvrir Trame-de-Rapport.xlsx, recopier le profil/score et le résumé du bilan dans les champs prévus en haut, cocher les indicateurs et choisir Oui pour les missions à proposer — le budget total se calcule automatiquement.

Deux détails pratiques

Pour un export PDF. Aucun bouton dédié : utilisez la fonction native d'Excel, Fichier → Exporter → Créer un PDF/XPS (disponible sur PC/Mac, pas sur les applications mobiles Excel).
Si Excel affiche un bandeau de sécurité à l'ouverture du fichier Integrateur-de-Balance.xlsm (le seul des trois avec une macro), cliquez sur Activer le contenu pour utiliser le bouton d'import automatique — ou ignorez ce bandeau et collez vos données à la main dans l'onglet Données, qui fonctionne sans aucune macro.
